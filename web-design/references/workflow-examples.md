# Workflow Examples

These examples clarify how the same skill adapts to different tasks.

## A. New landing page from a text brief

1. Extract conversion goal, audience, message hierarchy, required content, and technical constraints.
2. Establish a visual thesis and typography/composition strategy.
3. Create the page structure and visual system.
4. Implement the first coherent version.
5. Render desktop and mobile.
6. Review for art direction, hierarchy, composition, and generic-AI patterns.
7. Fix only the top 1–3 mismatches.
8. Repeat until the completion gate passes.

## B. Screenshot to HTML

1. Treat the screenshot as primary visual truth.
2. Determine target viewport and major geometry.
3. Implement macro regions before micro styling.
4. Match typography and wrapping.
5. Render at the same viewport.
6. Identify the 1–3 largest visual mismatches.
7. Correct and re-render.
8. Only after large differences are resolved, refine details.

## C. Existing site redesign

1. Inspect existing hierarchy, brand assets, content, SEO-critical information, and conversion path.
2. Decide what must remain recognizable.
3. Establish a new art direction that solves the stated problem.
4. Recompose rather than merely restyle old cards.
5. Preserve technical architecture unless change is justified.
6. Render and review both brand continuity and design quality.

## D. Interactive prototype

1. Define the experience and key interaction states.
2. Establish visual direction before building controls.
3. Implement only interactions that support the concept or user flow.
4. Render meaningful content immediately.
5. Review static composition and interaction states separately.
6. Fix the top visual/interaction mismatches per iteration.

## E. Mobile redesign from desktop

1. Preserve content priority and art direction, not desktop geometry.
2. Re-evaluate navigation, hero, image crop, type scale, and density.
3. Decide what becomes sequential, scrollable, collapsed, or removed.
4. Produce a mobile composition intentionally.
5. Review on narrow widths for hierarchy and touch behavior.
