# Web Design — Listing

**Name:** Web Design  
**Publisher:** max0821  
**Version:** 1.3.0  
**Type:** Skill-only plugin  
**Official source:** https://github.com/max0821/web-design-skill  
**License:** MIT

**Short description:** Visual-first web design with approved targets, design-to-code fidelity, asset locking, and render-based QA.

**Long description:** Web Design is a visual-first Agent Skill for designing, redesigning, and reconstructing polished websites without generic AI UI. It establishes art direction and an approved visual target, decomposes it into Block, Layer, Text, and Geometry maps, locks accepted assets to prevent target drift, implements semantic frontend code, and iterates against the rendered result by fixing only the 1–3 highest-impact mismatches per pass.
