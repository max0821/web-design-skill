# Web Design — 上架文案

**名稱：** Web Design  
**發布者：** max0821  
**版本：** 1.3.0  
**類型：** Skill-only plugin  
**官方來源：** https://github.com/max0821/web-design-skill  
**授權：** MIT

**短描述：** 以核准視覺稿為核心的 Web Design Skill，維持 design-to-code fidelity、asset lock 與 render-based QA。

**長描述：** Web Design 是一套 visual-first Agent Skill，用於設計、改版與精準重建網站，避免制式 AI UI。它先建立 Art Direction 與 Approved Visual Target，再拆成 Block、Layer、Text、Geometry 四個 Map，鎖定已驗收素材避免 target drift，最後以語意化前端實作並根據實際 Render 每輪只修正 1–3 個最高影響的 mismatch。
